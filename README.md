Project Description
This repository contains a demonstration of a multi-stage authentication flow, including a login system, One-Time Password (OTP) verification, and JWT-based session management. The goal of this assignment was to successfully navigate the authentication process to access a protected route and retrieve a hidden success flag.

Authentication Flow
The following steps were completed to retrieve the flag:

User Login: Sent a POST request with credentials to initialize a session.

OTP Verification: Verified the session using a 6-digit code generated by the server.

Token Retrieval: Used the verified session cookie to obtain a JSON Web Token (JWT).

Protected Access: Provided the JWT in the Authorization header to unlock the /protected endpoint.

Files in this Repository
server.js: The main application logic and authentication middleware.

output.txt: A log of the terminal commands and server responses showing the successful retrieval of the flag.

cookies.txt: The cookie jar used to maintain session state between requests.

Success Flag
The final retrieved flag is: FLAG-PHjHhm1TZXRza...vNTSUKO1UKWA==
